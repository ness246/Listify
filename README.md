# 🛒 Listify - Düzen, Basitçe

Modern ve kullanıcı dostu market listesi uygulaması. Ürünlerinizi virgülle ayırarak yazın, Listify otomatik olarak numaralı liste oluştursun!

## ✨ Özellikler

- ✅ **Kolay Kullanım** - Virgülle ayır, liste otomatik oluşsun
- 🎯 **Tıklama Özelliği** - Ürünlere tıkla, tamamlandı olarak işaretle
- 📱 **Responsive Tasarım** - Telefonda ve bilgisayarda mükemmel çalışır
- 🎨 **Modern Arayüz** - Koyu tema ve smooth animasyonlar
- 🔄 **İşlem Butonları** - Tümünü sıfırla, tamamlananları sil
- 💾 **Local Storage** - Liste otomatik kaydedilir

## 🚀 Hızlı Başlangıç

### Yöntem 1: GitHub Pages (Önerilen)
1. GitHub Pages demo linkine tıklayın
2. Hemen kullanmaya başlayın!

### Yöntem 2: Lokal Kullanım
```bash
# Repository'yi klonlayın
git clone https://github.com/ness246/Listify.git

# Proje klasörüne gidin
cd listify

# index.html dosyasını tarayıcıda açın
```

### Yöntem 3: Doğrudan HTML
1. `index.html` dosyasını indirin
2. Herhangi bir tarayıcıda açın
3. Hemen kullanmaya başlayın!

## 🎯 Kullanım

1. **Ürünleri virgülle ayırarak yazın:**
   ```
   elma, süt, ekmek, yumurta, peynir
   ```

2. **"Liste Oluştur" butonuna tıklayın**

3. **Ürünlere tıklayarak tamamlandı olarak işaretleyin**

4. **Ek özellikler:**
   - **🔄 Tümünü Sıfırla**: Tüm işaretlemeleri temizler
   - **🗑️ Tamamlananları Sil**: Tamamlanan ürünleri listeden kaldırır
   - **🗑️ Temizle**: Tüm listeyi temizler
